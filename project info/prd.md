# 2. Product Overview

**PlayTalk** is a mobile application that combines private friend-to-friend communication with YouTube content management.

Users can create an account using their email and password, receive a unique PlayTalk User ID, add other users as friends, communicate through real-time one-to-one chat, and share YouTube videos and playlists with their friends.

The application will also provide functionality for saving and managing YouTube video and playlist references and, where permitted by the platform and applicable rights, supporting offline/download workflows.

### Core Concept

> **Watch. Share. Talk.**

---

# 3. Problem Statement

Users currently use separate applications for watching YouTube content, sharing videos with friends, and discussing that content.

For example:

1. User finds a useful YouTube video.
2. Copies the YouTube link.
3. Opens another messaging application.
4. Finds the friend.
5. Sends the link.
6. Returns to YouTube.

This creates a fragmented experience.

**PlayTalk aims to provide a single application where users can manage YouTube content and communicate with friends in one place.**

---

# 4. Product Goals

The primary goals of PlayTalk are:

* Provide simple email/password authentication.
* Generate a unique User ID for every user.
* Allow users to find and add friends using their User ID.
* Provide private one-to-one real-time messaging.
* Allow users to add and manage YouTube videos and playlists.
* Allow users to share YouTube content through chat.
* Provide a personal content library.
* Support permitted offline/download workflows.
* Provide a simple, modern and mobile-friendly interface.

---

# 5. Non-Goals

The following features are outside the MVP scope:

* Group chats
* Public chat rooms
* Study rooms
* Voice calls
* Video calls
* Public social feed
* Followers/following system
* Stories
* Public content discovery
* Live streaming
* AI chatbot

These features may be considered in future versions.
